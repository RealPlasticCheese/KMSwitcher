Choose a target, then download and open its build launcher, or copy the PowerShell command. Builds run in a separate window using the repo's pinned ESP-IDF setup. One receiver image works for all S2 receivers.

      

      
      

      

      
The browser prepares the launcher; open the downloaded .cmd file to start the build. Building does not flash hardware.

      
You can also double-click build-all.cmd, build-controller.cmd or build-receivers.cmd in the web folder. The build window shows progress, reports failures and pauses before closing.
